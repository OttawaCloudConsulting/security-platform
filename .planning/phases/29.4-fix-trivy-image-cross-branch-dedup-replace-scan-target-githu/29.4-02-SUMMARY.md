# Phase 29.4 Plan 02: trivy-image dedup assertion, offline replay and ci/main image diff Summary

`assert-pr-duplicates` no longer excludes the trivy-image Test. It now requires every PR trivy-image finding with a title counterpart in the ci/main trivy-image Test to be a duplicate of that counterpart. The check runs as one marker-delimited jq program (`TRIVY_IMAGE_VERDICT`). Run offline against the real 29-16 data, that same committed program fails 59 of 59 matched findings.

## Deviations from Plan

1. **[Rule 1 - Robustness] Replay compile check.** The plan said to abort when "`jq -n` reports a compile error". The replay instead runs the extracted program on `{"findings": []}` inputs and exits 2 on any jq error, compile or runtime. This is stricter and does not depend on error-message wording.
2. **[Rule 3 - Tooling] Trailing whitespace stripped from the evidence file** for the docs-repo pre-commit hook. This is noted in the file header.

There were no other deviations. The DUPLICATES-POINT-TO-MAIN PASS/FAIL messages already said "non-fixture, non-trivy-image". Only the vacuity message carried "excluded" wording, and it was rewritten.

**2. Confirm ESLint hook behavior**

**Test:** Stage a `.ts` file and attempt `pre-commit run eslint` in `repos/aws-zabbix-monitoring-solution/`.
**Expected:** Either the hook executes (eslint is available via npx), or the hook errors with a clear message about missing eslint.

This is a runtime gap, not a config syntax error.

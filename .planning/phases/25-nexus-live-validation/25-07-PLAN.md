    `argocd.argoproj.io/hook: Sync`, and Argo CD ignores **all** Helm hooks on a resource that carries any

    what converts ADR-020 item 3 from training knowledge into an observation.
  - NEXUS-03's live proof: quote the measured cluster default StorageClass name, the PVC phase and size
    from `25-04-SUMMARY.md`, and note that the provisioner is `WaitForFirstConsumer` so a PVC is
    legitimately Pending until the StatefulSet pod schedules.
  - NEXUS-02's live proof: quote the four measured byte counts (npm tarball, PyPI simple page, Helm
    `index.yaml`, Docker layer blob), the five-leg OCI handshake result, and the point that a ~192-byte
    body would mean the EULA was never accepted and a 0-byte body a 401 challenge — which is why three
    separate verdicts per fetch exist.
  - The Docker path shape, both directions: quote the 200 on `HOST/<repo>/<image>` and the 404 on the
    `/repository/` analogy shape.
  - The write boundary: quote the exact 403 on a **structurally valid** unauthenticated POST, the 200
    instrument check on an existing repository, and the 404 non-creation readback. State that a 400 would

  - Idempotency against existing state: quote the second-sync counts (`action=updated` ×4,
    `action=created` ×0) and the exact active-realms array from `25-05-SUMMARY.md`. State that Argo CD
    re-runs Sync hooks on **every** sync and that `ApplyOutOfSyncOnly=true` does not suppress them, so
    "DockerToken exactly once, NexusAuthenticatingRealm still present" is a standing invariant rather than
    a one-off test.
  - A green sync is not evidence: Argo CD decides a hook phase purely from the Job's exit code, so
    Synced + Healthy was explicitly not accepted as NEXUS-05 closure.

`## Decision` — the choices this phase made, each with its reason:
  1. Amend the existing `platform` AppProject rather than create a new `security` project (operator
     decision, taken against the research recommendation; the directory path `application-sets/platform/nexus/`
     permanently fixes the Application's project). Record that the pre-existing unscoped `''/Namespace`
     entry was deliberately left byte-unchanged because narrowing it would revoke namespace creation for
     the other `platform` members, and that resource kinds were enumerated from a fresh render rather than
     wildcarded.
  2. A two-source Application: source 1 the public `security-platform` chart pinned to an immutable commit
     SHA, source 2 the overlay directory carrying only the SealedSecret. Record the SHA and that a pin
     means chart updates require an overlay commit.
  3. The admin credential delivered as a SealedSecret at sync-wave `-1`, with the measured caveat that
     Argo CD has **no health assessment** for `bitnami.com/SealedSecret` on this cluster, so the wave
     orders the apply but cannot wait for decryption.
  4. **Ingress and TLS excluded from this phase, deliberately.** Record the reasons: there is no
     IngressClass and no Gateway API on the cluster, so an `Ingress` would be created and route nothing;
     the convention is a LoadBalancer VIP, and the VIP pool is operator-owned; and validating over
     `kubectl port-forward` keeps unauthenticated plaintext on loopback rather than putting it on the LAN.
     State plainly that this means ADR-021 `## What was NOT verified` item 4 is **still open** and is not
     closed by this record.
  5. The chart-edit verdict from `evidence/25-05-chart-edit-assessment.md`, quoted with its evidence.
  6. Validation instrument: a sibling `scripts/nexus-homelab-validate.sh` rather than parameterising
     `nexus-live-smoke.sh` in place, so the existing 25-check gate stayed untouched and green; `--url`,
     `--context` and `--sync-pass` all required with no defaults.

`## Consequences` — using ADR-021's labels:
  - `**Improved:**` the chart is proven on a long-lived cluster through the project's own GitOps path; the
    "generic-first, not private-then-strip" architecture decision has its first live exercise; NEXUS-03's
    default-StorageClass claim is measured rather than asserted; ADR-021 item 7 is closed.
  - `**Tradeoff — a shared AppProject is now wider:**` the other `platform` members may create
    StatefulSets, Jobs and SealedSecrets. Record the alternative that was rejected and why.
  - `**Tradeoff — anonymous read is open on a real network:**` `nx-anonymous` is wildcard read-only across
    format and repository name, so any repository added later is world-readable from creation, and
    `GET /service/rest/v1/repositories` answers 200 anonymously. No NetworkPolicy ships and none is in
    milestone scope; reach is currently limited only by the absence of an ingress.
  - `**Tradeoff — everything is plaintext:**` no TLS anywhere in this path; loopback-only validation was
    the interim control.
  - `**Tradeoff — a SHA pin:**` chart updates need an overlay commit.
  - `**Tradeoff — the PVC reclaim policy:**` record the confirmed size and reclaim policy from
    `25-02-SUMMARY.md` and that losing the volume costs re-accepting the EULA and re-provisioning. Note
    that `helm uninstall` / Argo prune does not necessarily delete the PVC, and that re-creating the
    Application against a surviving PVC is the re-entrant path — which is itself what ADR-021 item 7 tested.
  - `**Tradeoff — deleting one file deletes the Application:**` `preserveResourcesOnDeletion: true` on the
    generator leaves the workloads behind unmanaged, so a rollback removes the workloads first.

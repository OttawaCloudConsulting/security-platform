Run the second sync — the first time this provisioning path has ever met an instance whose PVC already
carries state — prove it is idempotent, record the workstation routing script's verdicts against the live
instance, and close 25-RESEARCH Open Question 3 (do the chart's Job annotations need correcting?) from
observation rather than prediction.

Purpose: ADR-021 `## What was NOT verified` item 7 states plainly that no `helm upgrade` of an existing
install was ever exercised — the guarded realms append was only ever proven across two provisioning passes
on a **fresh** instance. Under Argo CD this stops being a hypothetical: Sync hooks re-run on **every**
sync, `ApplyOutOfSyncOnly=true` does not suppress them, and `selfHeal: true` is on. So this Job will run
many times over the Application's life, and "DockerToken exactly once, NexusAuthenticatingRealm still
present" is a standing production invariant, not a one-off test.
Output: four evidence files, and a written decision on the two optional chart edits.
</objective>

- **After every operator write checkpoint:** run the matching read-only readback (ruleset GET, PR state, check-runs).
- **After every race attempt:** run the verdict jq over the attempt log. **Stop on the first "lost" (D-11).**
- **Before `/gsd:verify-work`:** every row below must be green, or explicitly deferred under D-17.
- **Max feedback latency:** 60 seconds per assertion.

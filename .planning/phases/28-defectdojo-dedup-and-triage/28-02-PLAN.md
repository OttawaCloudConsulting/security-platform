Write the idempotent DefectDojo System Settings bootstrap script (D-10) and prove its refusals offline, then add
it to the proof workflow's path filter.

Purpose: dedup is OFF on a fresh 3.3.200 install (RESEARCH Pitfall 1); without this script DDOJO-03 is inert. The
System Settings API is superuser-only (Pitfall 2), so the script takes an operator-held superuser token, never the
CI ci-importer token, and must meet the Phase 27 token idiom and ADR-025 https-only rule.

(DEFECTDOJO_ADMIN_TOKEN_FILE). The kind proof (28-03) derives such a file from its admin.hdr by stripping the
`Authorization: Token ` prefix into a fresh 0600 file, because admin.token is deleted at proof line 695.

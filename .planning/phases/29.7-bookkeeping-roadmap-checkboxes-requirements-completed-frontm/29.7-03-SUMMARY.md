## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The pre-commit `--check` rejected the harness output, so trailing whitespace is now stripped at write time and the evidence was regenerated**
- **Found during:** Task 2 (first evidence commit attempt)
- **Issue:** The repo's `.git/hooks/pre-commit` runs `git diff-index --check`, and it rejected the commit. Two sources had trailing whitespace:
  - the harness `flatten` helper left a trailing space on every paste-block `Actual:` line;
  - `diff -u` writes blank context lines as a single space.

  Nothing was committed.
- **Fix:**
  - Added `strip()` (`sed 's/[[:space:]]*$//'`) and piped every evidence and guard write through it.
  - Fixed `flatten`.
  - Documented the normalization in the script header.
  - Re-ran the harness once: exit 0, 11 `REAL-UNCHANGED`.
- **Determinism check:** After normalizing the marker, scratch paths, timestamps, HEAD and trailing whitespace, all 16 ledger files from run 1 and run 2 are byte-identical. Only the informational before/after `git status` blocks in the guard log differ: they list run 1's own uncommitted outputs.
- **Pre-flight:** `git diff --cached --check` was clean before the commit, and the hook passed.
- **Files modified:** `29.7-ledger-retest.sh` and all 18 evidence files (regenerated)
- **Commit:** `7f67f17`

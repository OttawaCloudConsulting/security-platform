Create `dist/install.sh` with the following structure. All code must be bash 3.2 compatible (no associative arrays, no mapfile, no |&, no &>, no ${var,,}, no grep -P, no readlink -f, no sed -i without empty arg).

**Section 1: Header and globals**
```bash
#!/usr/bin/env bash
set -euo pipefail

# install.sh -- Install security CLI tools (macOS and Linux)
# Usage: bash install.sh [-v|--verbose] [-h|--help]

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
VERBOSE=false
INSTALL_DIR="$HOME/.local/bin"
RESULTS=""
FAIL_COUNT=0
```

**Section 2: Helper functions**

`usage()` -- print usage text to stdout, listing -v/--verbose and -h/--help flags.

`log()` -- print "==> $*" to stdout only if VERBOSE=true.

`err()` -- print "ERROR: $*" to stderr.

`add_result()` -- append "tool|version|status\n" to RESULTS variable. Takes 3 args: tool, version, status (installed/skipped/failed).

`print_summary()` -- print end-of-run summary table. Header: "Security Tool Installation Summary" with dashes separator. Columns: Tool (%-14s), Version (%-12s), Status (%s). Parse RESULTS using `printf "%b" "$RESULTS" | while IFS='|' read -r tool version status`. After table, if FAIL_COUNT > 0, print "WARNING: $FAIL_COUNT tool(s) failed to install" to stderr.

`is_installed()` -- takes tool name and expected version. Returns 0 if `command -v "$tool"` succeeds AND version output (parsed via `"$tool" --version 2>&1 | head -1 | grep -oE '[0-9]+\.[0-9]+\.[0-9]+'`) matches expected. Returns 1 otherwise. Special case: gitleaks uses `gitleaks version` (no --), and the version output needs `grep -oE '[0-9]+\.[0-9]+\.[0-9]+'` to extract the semver.

`verify_sha256()` -- cross-platform checksum verification. Takes file path and expected hash. Uses `sha256sum` if available, else `shasum -a 256`. Compares actual vs expected, calls `err` and returns 1 on mismatch.

**Section 3: OS/Arch detection functions**

`detect_os()` -- echo "Darwin" or "Linux" from `uname -s`. Call `err` and `exit 1` for unsupported OS.

`detect_arch()` -- echo "arm64" or "x86_64" from `uname -m`, normalizing "aarch64" to "arm64". Call `err` and `exit 1` for unsupported arch.

Per-tool arch normalization functions (needed for Gitleaks and hadolint in Plan 02, but define them now):

`get_gitleaks_os()` -- Darwin -> "darwin", Linux -> "linux"
`get_gitleaks_arch()` -- x86_64 -> "x64", arm64|aarch64 -> "arm64"
`get_hadolint_os()` -- Darwin -> "macos", Linux -> "linux"
`get_hadolint_arch()` -- x86_64 -> "x86_64", arm64|aarch64 -> "arm64"

**Section 4: pipx bootstrap**

`ensure_pipx()` -- Check `command -v pipx`. If found, log "pipx already installed" and return. If not found:
1. Check `command -v python3` -- err and exit 1 if missing ("python3 is required but not found")
2. Log "Installing pipx via pip..."
3. Try `python3 -m pip install --user pipx 2>&1` (capture output to variable)
4. If that fails (check $?), try `python3 -m pip install --user --break-system-packages pipx 2>&1` with a warning about PEP 668
5. If both fail, err "Failed to install pipx. Install manually: https://pipx.pypa.io/stable/installation/" and exit 1
6. Run `python3 -m pipx ensurepath > /dev/null 2>&1 || true` to set up PATH in shell profiles

**Section 5: Tool installers**

`install_precommit()` --
1. Call `is_installed pre-commit "$PRECOMMIT_VERSION"` -- if 0, log "pre-commit $PRECOMMIT_VERSION already installed", `add_result "pre-commit" "$PRECOMMIT_VERSION" "skipped"`, return
2. Call `ensure_pipx`
3. Log "Installing pre-commit $PRECOMMIT_VERSION via pipx..."
4. Run `pipx install "pre-commit==$PRECOMMIT_VERSION"` (with output suppressed unless VERBOSE; if VERBOSE, let output through, otherwise redirect to /dev/null)
5. If install succeeds, `add_result "pre-commit" "$PRECOMMIT_VERSION" "installed"`
6. If install fails, `err "Failed to install pre-commit"`, `add_result "pre-commit" "$PRECOMMIT_VERSION" "FAILED"`, `FAIL_COUNT=$((FAIL_COUNT + 1))`

Stub functions for Plan 02 (will be replaced):
```bash
install_trivy()   { log "Trivy install: see Plan 02"; }
install_syft()    { log "Syft install: see Plan 02"; }
install_grype()   { log "Grype install: see Plan 02"; }
install_gitleaks() { log "Gitleaks install: see Plan 02"; }
install_hadolint() { log "hadolint install: see Plan 02"; }
```

**Section 6: PATH verification**

`verify_path()` -- Check if `$INSTALL_DIR` is in `$PATH`. If not, print warning to stderr: "WARNING: $INSTALL_DIR is not in your PATH. Add it to your shell profile or run: export PATH=\"\$HOME/.local/bin:\$PATH\""

Also check each tool with `command -v`: pre-commit, trivy, syft, grype, gitleaks, hadolint. For each one not found, print warning to stderr: "WARNING: {tool} not found on PATH".

**Section 7: Main execution flow**

1. Parse arguments: loop `for arg in "$@"`, case on -v|--verbose, -h|--help, * (unknown arg -> err + exit 1)
2. Source versions.conf: check file exists at `$SCRIPT_DIR/versions.conf`, source it, or err + exit 1
3. Create install dir: `mkdir -p "$INSTALL_DIR"`
4. Add to PATH for this session: `export PATH="$INSTALL_DIR:$PATH"`
5. Log "Installing security tools to $INSTALL_DIR"
6. Call each install function: install_precommit, install_trivy, install_syft, install_grype, install_gitleaks, install_hadolint
7. Call verify_path
8. Call print_summary
9. Exit with 1 if FAIL_COUNT > 0, else exit 0

Important implementation notes:
- Do NOT use `chmod +x` on the script (per project rules, scripts are invoked with explicit interpreter: `bash dist/install.sh`)
- Use `[[ ]]` for conditionals, not `[ ]`
- Quote all variables and command substitutions
- UPPERCASE for constants/globals, lowercase for local variables
- Comments explain non-obvious logic only
- Status messages prefixed with `==>` (via log function)
- Errors to stderr (via err function)
- Default output is minimal (errors + summary only). Verbose mode shows progress.

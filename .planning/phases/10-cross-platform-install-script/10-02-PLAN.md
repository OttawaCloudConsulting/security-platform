1. Call `is_installed` to check if correct version is already present -- skip if so
2. Download the tool
3. Place binary in `$INSTALL_DIR` (~/.local/bin)
4. Call `add_result` with appropriate status
5. On failure: call `err`, `add_result` with "FAILED", increment `FAIL_COUNT`, but do NOT exit (continue to next tool)

**install_trivy():**
```bash
install_trivy() {
  if is_installed trivy "$TRIVY_VERSION"; then
    log "trivy $TRIVY_VERSION already installed"
    add_result "trivy" "$TRIVY_VERSION" "skipped"
    return
  fi
  log "Installing trivy $TRIVY_VERSION via official script..."
  if curl -sfL "$TRIVY_INSTALL_URL" | sh -s -- -b "$INSTALL_DIR" "v${TRIVY_VERSION}" > /dev/null 2>&1; then
    add_result "trivy" "$TRIVY_VERSION" "installed"
  else
    err "Failed to install trivy $TRIVY_VERSION"
    add_result "trivy" "$TRIVY_VERSION" "FAILED"
    FAIL_COUNT=$((FAIL_COUNT + 1))
  fi
}
```
When VERBOSE=true, do NOT redirect to /dev/null -- let the official script output show. Use a conditional: `if [[ "$VERBOSE" = true ]]; then ... else ... fi` or use a variable for the redirect.

**install_syft():** Same pattern as install_trivy but using `$SYFT_INSTALL_URL` and `$SYFT_VERSION`. The Anchore install script uses the same -b flag and version format.

**install_grype():** Same pattern as install_trivy but using `$GRYPE_INSTALL_URL` and `$GRYPE_VERSION`.

**install_gitleaks():**
This is a direct binary download, NOT an official install script. Implementation:
1. idempotency check with `is_installed gitleaks "$GITLEAKS_VERSION"` -- note: gitleaks uses `gitleaks version` (no --version flag), so `is_installed` must handle this. If `is_installed` already does generic parsing, verify it works for gitleaks. If not, add special handling.
2. Get OS/arch via `get_gitleaks_os` and `get_gitleaks_arch`
3. Build download URL by replacing {VERSION}, {OS}, {ARCH} in `$GITLEAKS_URL`:
   ```bash
   local url="$GITLEAKS_URL"
   url="${url//\{VERSION\}/$GITLEAKS_VERSION}"
   url="${url//\{OS\}/$os}"
   url="${url//\{ARCH\}/$arch}"
   ```
   NOTE: `${var//pattern/replacement}` IS bash 3.2 compatible (it's parameter expansion, not a bashism that was added later).
4. Build checksums URL same way from `$GITLEAKS_CHECKSUMS_URL`
5. Create tmpdir: `mktemp -d "${TMPDIR:-/tmp}/gitleaks.XXXXXX"`
6. Download tarball and checksums.txt to tmpdir
7. Extract expected hash from checksums.txt: `grep "gitleaks_${GITLEAKS_VERSION}_${os}_${arch}.tar.gz" "$tmpdir/checksums.txt" | cut -d' ' -f1`
8. Call `verify_sha256 "$tmpdir/gitleaks.tar.gz" "$expected_hash"`
9. Extract: `tar -xzf "$tmpdir/gitleaks.tar.gz" -C "$tmpdir"`
10. Move binary: `mv "$tmpdir/gitleaks" "$INSTALL_DIR/gitleaks"` and `chmod +x "$INSTALL_DIR/gitleaks"`
11. Clean up: `rm -rf "$tmpdir"`
12. add_result

Architecture naming reference for Gitleaks (CRITICAL -- verified from live releases):
- macOS arm64: os=darwin, arch=arm64
- macOS x86_64: os=darwin, arch=x64 (NOT x86_64, NOT amd64)
- Linux aarch64: os=linux, arch=arm64
- Linux x86_64: os=linux, arch=x64

**install_hadolint():**
Direct binary download (NOT a tarball -- it's a raw binary). Implementation:
1. idempotency check with `is_installed hadolint "$HADOLINT_VERSION"`
2. Get OS/arch via `get_hadolint_os` and `get_hadolint_arch`
3. Build download URL by replacing {VERSION}, {OS}, {ARCH} in `$HADOLINT_URL`
4. Build checksum URL from `$HADOLINT_CHECKSUM_URL`
5. Create tmpdir: `mktemp -d "${TMPDIR:-/tmp}/hadolint.XXXXXX"`
6. Download binary and .sha256 file to tmpdir
7. Extract expected hash: `cut -d' ' -f1 < "$tmpdir/hadolint.sha256"` (hadolint .sha256 files contain just the hash or hash + filename)
8. Call `verify_sha256 "$tmpdir/hadolint" "$expected_hash"`
9. `chmod +x "$tmpdir/hadolint"` then `mv "$tmpdir/hadolint" "$INSTALL_DIR/hadolint"`
10. Clean up: `rm -rf "$tmpdir"`
11. add_result

Architecture naming reference for hadolint (CRITICAL -- verified from live releases):
- macOS arm64: os=macos (lowercase!), arch=arm64
- macOS x86_64: os=macos, arch=x86_64
- Linux aarch64: os=linux, arch=arm64
- Linux x86_64: os=linux, arch=x86_64

       with the EULA unaccepted, the pod is Ready, `helm status` is `deployed`, all proxy repos
       appear correctly in the UI, and metadata requests return HTTP 200 — while every actual
       package download returns HTTP 403 with a 192-byte body. Setting `eula.accepted: true`
       makes the provisioning Job accept it, after which the same request returns 200. Link
       `https://links.sonatype.com/products/nxrm/ce-eula` and state that the chart deliberately
       does not accept a licence agreement on the consumer's behalf.

    3. **Helm proxy has no default remote (`repos.helm.remoteUrl`).** Explain why: Helm Hub has
       been defunct since 2020; Artifact Hub is a cross-repo search index, not a chart
       repository serving a single `index.yaml`, which is what a Nexus `helm` proxy requires;
       and Bitnami's repository is mid-deprecation through 2026. State the consequence
       concretely — with the value unset, three proxy repositories are created (npm, pypi,
       docker) and the Helm proxy is not; set it to a repository relevant to your stack, e.g.
       `https://charts.jetstack.io`, `https://prometheus-community.github.io/helm-charts`, or
       an ingress-nginx repository.

    4. **Community Edition ceiling.** 40,000 total components and 100,000 requests per day;
       beyond either, CE pauses the addition of new components until usage drops below both.
       Note that because the Nexus version floats with the subchart's `appVersion` (D-08), a
       future chart bump can change these limits without any change in this repository, and
       that `Chart.lock` is the control point.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local branch -> public `main` | everything merged becomes publicly consumable and is what other repositories reference |
| agent judgement -> irreversible action | a merge to a public default branch cannot be cleanly undone |
| local working tree -> remote truth | the local tree can look correct while the remote does not; this project has recorded that failure twice |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-14 | Elevation of privilege | unauthorised merge to a public default branch | mitigate | blocking `checkpoint:human-verify` in Task 2; the operator's own reply is the only authorisation, and no `auto_advance` setting overrides it |
| T-23-12 | Repudiation | merge verification | mitigate | verification reads `origin/main` after `git fetch` via `git ls-tree` / `git show`, never the local tree; the merge commit SHA and both parents are recorded |
| T-23-02 | Information disclosure | publishing the chart | mitigate | the chart carries no credential: `nexus3.rootPassword.secret` has no default, gitleaks passed on the whole tree in plan 23-06, and the READMEs carry no literal password example |
| T-23-SC | Tampering | npm/pip/cargo installs | mitigate | none occur; what becomes public is a chart whose only dependency is pinned by a committed `Chart.lock` and whose helper images are digest-pinned |
| T-23-15 | Tampering | vendored tarball leaking to the remote | mitigate | acceptance criterion asserts no path under `kubernetes/nexus/charts/` exists on `origin/main` |
</threat_model>

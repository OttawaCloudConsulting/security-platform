<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer values -> rendered JSON request body | `remoteUrl` and repository names are untrusted input crossing into a REST payload |
| Kubernetes Secret -> Job process env | the admin credential crosses into a container that makes outbound HTTP calls |
| Job -> Nexus REST API | privileged administrative configuration over in-cluster plain HTTP |
| Nexus -> upstream registries | proxied content enters the cluster's supply chain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

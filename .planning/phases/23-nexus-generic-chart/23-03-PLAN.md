## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public Helm chart -> every future consumer | defaults shipped here are applied on somebody else's cluster, under somebody else's legal identity |
| upstream chart repository -> this chart | an unpinned dependency resolves to whatever the repo serves at install time |
| container registry -> the cluster | a mutable image tag resolves to different bytes over time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-02 | Spoofing / Info disclosure | `values.yaml` admin credential | mitigate | `nexus3.rootPassword.secret` is a Secret **name** with no default and no literal-password key anywhere; enforced at render time by plan 23-04's `required` |
| T-23-03 | Elevation of privilege | Groovy scripting API | mitigate | `nexus3.config.enabled: false` ships as a default and is asserted by the `CONFIG-DISABLED` check; the property `nexus.scripts.allowCreation=true` is never emitted |
| T-23-05 | Repudiation | Community Edition EULA | mitigate | `eula.accepted: false` default (D-09) — the chart never accepts a licence agreement on a consumer's behalf; the EULA URL is carried in the values comment |
| T-23-04 | Tampering | `repos.*.remoteUrl` | mitigate | remotes are declarative values only in this plan; plan 23-04 renders them through `toJson`, never string concatenation |
| T-23-SC | Tampering | npm/pip/cargo installs | mitigate | no package-manager install occurs. The Helm/OCI equivalent is covered: `Chart.lock` pins `stevehipwell/nexus3` 5.26.0 (MIT, ArtifactHub verified publisher, adopted by explicit user decision D-01 REVISED after the deprecation of every Sonatype-published alternative), and both helper images are digest-pinned to values measured live in 23-RESEARCH.md §Package Legitimacy Audit |
| T-23-09 | Denial of Service | `nexus3.persistence.enabled` | mitigate | default `true` (D-10) — the upstream `false`/emptyDir default would discard EULA acceptance and all proxy repos on every pod restart |
</threat_model>

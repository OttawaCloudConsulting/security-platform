    `## Context` — bolded lead clause per bullet, then measured detail:
      - No Sonatype-published Helm chart named `nexus3` exists. `helm search repo sonatype`

      - Since Nexus 3.77.0 the free edition is Community Edition and ships an unaccepted EULA
        that returns HTTP 403 on every component download while metadata returns 200 — measured
        end to end on a fresh 3.96.0 container: tarball 403 at 192 bytes, then
        `POST /service/rest/v1/system/eula` returns 204, then the identical request returns 200
        at 318,961 bytes. `nexus.loadAsOSS=true` does not bypass it.
      - The upstream chart's built-in provisioning Job re-enables the deprecated Groovy
        scripting API (`nexus.scripts.allowCreation=true`) that `POST /service/rest/v1/script`
        otherwise refuses with 410.
      - Helm Hub has been defunct since 2020 and Artifact Hub is a cross-repo search index, not
        a chart repository serving one `index.yaml`.

    `## Decision` — bolded lead clause per bullet:
      - Wrap the community `stevehipwell/nexus3` 5.26.0 chart as a subchart dependency (MIT,
        ArtifactHub verified publisher, runs Sonatype's official `docker.io/sonatype/nexus3`
        image), pinned by a committed `Chart.lock`; do not fork or vendor it.
      - Ship a purpose-built post-install/post-upgrade hook Job rather than enabling the
        upstream config Job, keeping `nexus3.config.enabled: false` so the Groovy API stays off.
      - Make EULA acceptance an explicit opt-in (`eula.accepted: false` by default). A public
        chart must not accept a licence agreement on a consumer's behalf.
      - Ship no default for the Helm proxy remote; document consumer-appropriate examples.
      - Ship no admin password: `nexus3.rootPassword.secret` names a consumer-created Secret
        and is `required` at render time.
      - Set `nexus3.persistence.enabled: true` and leave `nexus3.persistence.storageClass`
        omitted so Kubernetes substitutes the cluster default (NEXUS-03).

    `**Tradeoff — <one-line name>.**` paragraphs. At minimum name these tradeoffs: an unsigned

    publisher" attests domain control, not code review); NEXUS-01's Helm proxy is configured

Create the live half of the phase's evidence: a docker-driven smoke test that boots a real
Nexus Community Edition container, runs the chart's own provisioning script twice, and proves
a real package tarball downloads after EULA acceptance — plus an optional kind install smoke.

provision.sh environment contract:
  NEXUS_HOST        http://<host>:<port>   — no trailing slash
  NEXUS_USER        always the literal "admin"
  NEXUS_PASSWORD    the admin password; never echoed, never logged
  EULA_ACCEPTED     the string "true" or "false" (D-09 opt-in)
  REPO_CONFIG_DIR   directory holding the repo body JSON files; default "/config"

provision.sh repo body contract:
  files are ${REPO_CONFIG_DIR}/NNN-<format>.json, glob-ordered:
    000-npm.json  001-pypi.json  002-docker.json  003-helm.json
  003-helm.json exists only when repos.helm.remoteUrl is set (D-05)
  the Nexus repository FORMAT comes from the filename; the repository NAME comes from
  `jq -r .name` on the body

provision.sh exit contract:
  0  success — and it must exit 0 on BOTH of two consecutive runs (idempotent)
  1  readiness poll exhausted (60 attempts x 10s), or EULA POST != 204, or any repo
     upsert status outside {200 (GET hit), 201 (POST create), 204 (PUT update)}

Chart-derived inputs (never hardcode these — read them out of the chart):
  Nexus image:  helm template … | yq 'select(.kind=="StatefulSet")|.spec.template.spec.containers[0].image'
  Repo bodies:  helm template … | yq 'select(.kind=="ConfigMap" and (.metadata.name|test("-repos$")))|.data'

Positive-render wrapper (identical to scripts/check-nexus-chart.sh):
```bash
render() {
  helm template t kubernetes/nexus \
    --set nexus3.rootPassword.secret=dummy-secret-name "$@"
}
```

| Scanner report JSON → `scripts/smoke-scans.sh` verdict | Untrusted, tool-produced input parsed by the gate that decides pass/fail |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-06 | Tampering | A stale README claim invites a future maintainer to add a fifth `exclude: ^fixtures/` or a `.gitleaksignore` fingerprint, silencing a CI control | mitigate | Edit points 4 and 5 replace both stale claims in the same commit that falsifies them, and each replacement states the prohibition with its reason rather than only the fact |
| T-19-07 | Spoofing | A local gate that prints findings but asserts nothing reports PASS while the fixture is silent | mitigate | Two verdict blocks asserting rule id AND path, routed through `FAILURES+=`, each observed firing against a filtered and an invalid report before the commit |
| T-19-08 | Denial of Service | An unguarded assertion aborts the whole smoke gate under `set -euo pipefail`, turning one fixture regression into a gate that reports nothing | mitigate | Every assertion is `|| rc=$?`-guarded and routed to `FAILURES+=`; `bash -n` plus shellcheck plus the extracted-heredoc tests confirm it before commit |

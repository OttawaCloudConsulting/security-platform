| Boundary | Description |
|----------|-------------|
| Executor → `main` of a shared live public repository | A merge is irreversible in practice and makes the synthetic credential permanent in every future branch's history |
| Local working tree → claims about `origin/main` | The local checkout may be on any branch; only `git show origin/main:…` is evidence |
| Phase record → downstream phases | An unrecorded open question becomes an untested assumption in Phase 20's consumer template |

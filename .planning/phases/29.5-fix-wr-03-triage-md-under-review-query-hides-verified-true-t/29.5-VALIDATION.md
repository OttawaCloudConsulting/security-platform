- **After every task commit:** Run the quick commands plus `shellcheck` on touched scripts
- **After every plan wave:** Run the full kind proof (CI on PR A) for waves touching the harness or `security.yml`
- **Before `/gsd:verify-work`:** Full suite green, live D-12 diff verdict recorded, impact check and tag readback recorded
- **Max feedback latency:** ~10 seconds for static gates

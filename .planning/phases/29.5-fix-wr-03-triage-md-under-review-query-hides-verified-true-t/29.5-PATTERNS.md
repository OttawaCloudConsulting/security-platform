## Shared Patterns

### A. Proof tally (all new P-labels)
**Source:** `defectdojo-import-proof.sh` L411-445.
```bash
proof_pass() { PROOF_N=$((PROOF_N + 1)); echo "PROOF: $1 PASS $2"; }
proof_fail() { PROOF_N=$((PROOF_N + 1)); PROOF_FAILED=$((PROOF_FAILED + 1)); echo "PROOF: $1 FAIL $2"; }
proof_skip() { echo "PROOF: $1 SKIP $2"; }          # never counted
proof_abort() { proof_fail "$1" "$2"; echo "    aborting: ..."; proof_finish; }   # DO NOT use in P-VERIFIED-*
```
The rule: a failure in a late group is `proof_fail` plus `return 0`, so that earlier groups (P-IMAGE-TAG and the others) stay visible. Measurement-only labels (P-VERIFIED-RESET, P-VERIFIED-REACTIVATE) must print the measured values verbatim in the PASS detail. Do not hide an operator decision inside a silent pass.

### B. Fresh-product isolation
**Source:** L194-200 (readonly constants with a Phase comment) and L2591-2594 (export). Every case gets its own product, because dedup is product-wide and would otherwise contaminate the controls.

### C. Gate failure plus scratch negatives
**Source:** `check-workflow-uploads.sh` `fail(label, msg)` with a `(Phase X D-n, ADR-0NN)` suffix; the self-test override `WORKFLOWS_DIR` (header L62-64, read at L63); evidence format `29.4-01-image-tag-gate.txt`. No CI workflow runs this gate. It is a local or plan-verify gate.

### D. Token and TLS idiom (kind admin writes and the live reset)
**Sources:** `api_call` L446-456 (`curl -q -sS --cacert … -w '%{http_code} %{ssl_verify_result}'`, header by `-H @file`); `security.yml` L1553 (`["curl", "-q", "-sS", "--proto", "=https", "--proto-redir", "=https", …]`); TRIAGE.md L74-79 (the 0600 header file). The token never goes on argv. `-q` is always argv[1] (ADR-029), and the protocol is https only (ADR-025).

### E. Measured-claim labelling in docs
**Source:** TRIAGE.md L14 ("Measured live (Phase 29.4): …"). Apply it to TRIAGE.md L44, the guide bullet and ADR-032: each claim says whether it was measured in kind or live, and the STATE 28-06 rule applies (evidence, not prediction).

### F. Script hygiene
- No executable bit on any new script. Invoke it with `bash` or `python3`.
- `shellcheck` must be clean on every touched `.sh`.
- `# shellcheck disable=SC2016` goes on single-quoted jq programs.
- No `|| true` silent fallbacks in the guide. The harness's existing `|| rc=$?` capture pattern is the accepted form.

### G. Append-only ADRs
ADR-026 stays byte-unchanged (`git diff --stat -- docs/adr/adr026-*.md` must be empty). Supersession happens in ADR-032's own text.

### 5. `kubernetes/defectdojo/templates/validate-tls.yaml` (render-time guard)

**Analog (partial):** `repos/security-platform/kubernetes/nexus/templates/job-provision.yaml` lines 23-44 —
the repo's only existing render-time guard. Copy its **shape** (a `{{/* ... */}}` block comment explaining WHY
and the message↔gate coupling, then a side-effect-only expression that emits nothing):
```yaml
{{/*
UNCONDITIONAL admin-Secret guard — deliberately OUTSIDE the provision.enabled
block below.
...
The assignment to `$_` is how a `required` is evaluated for its side effect
without emitting anything into the manifest stream.

The message text must keep naming `nexus3.rootPassword.secret` verbatim: the
NO-DEFAULT-PASSWORD check in scripts/check-nexus-chart.sh asserts a bare render
fails AND that the failure names that value, so a reworded message that no
longer mentions it would turn that check red.
*/}}
{{- $_ := required "A Nexus admin password Secret is required. Create a Secret holding the admin password and name it in nexus3.rootPassword.secret (the key defaults to 'password'); this chart deliberately ships no default credential." .Values.nexus3.rootPassword.secret -}}
```
**Body:** `required` cannot be used literally (RESEARCH Summary finding 2 — the issuer lives in the
subchart's annotation map). Use RESEARCH Pattern 1 (lines 205-222) verbatim: `fail` when ingress+TLS on and
neither `cert-manager.io/cluster-issuer` nor `cert-manager.io/issuer` is set, when both are set, or when
`secretName` is empty. The comment block must name the gate checks that grep the message
(ISSUER-REQUIRED greps `cert-manager.io/cluster-issuer`), exactly as the Nexus comment names NO-DEFAULT-PASSWORD.

**No `_helpers.tpl`.** Nexus ships `templates/_helpers.tpl` with `define "nexus.fullname"` etc. (lines 6, 17,
52, 63, 90). DefectDojo must not: any `define "defectdojo.*"` silently overrides the subchart's helpers
(RESEARCH Pitfall 1, measured). If a helper is ever needed, prefix `ddwrap.*`.

```bash
REPO_ROOT="$(cd "$(dirname "$0")/.." && pwd)"
cd "$REPO_ROOT"

CHART_DIR="kubernetes/nexus"
VALUES="${CHART_DIR}/values.yaml"

# ── Preflight 3. Required binaries. Exit 2 — infrastructure, not a defect. ───
for bin in helm yq jq; do

  fi
done

# ── Preflight 4. Vendored subchart tarball. Exit 2 — infrastructure. ─────────
if ! compgen -G "${CHART_DIR}/charts/*.tgz" >/dev/null; then

  echo "run: helm dependency build ${CHART_DIR}"
  exit 2
```

DefectDojo: Guard 2 keys on `templates/validate-tls.yaml` (RESEARCH line 349).

**render() / fail() / unquote()** (lines 89-108):
```bash
render() {
  helm template t kubernetes/nexus \
    --set nexus3.rootPassword.secret=dummy-secret-name "$@"
}

FAILURES=()

fail() {
  FAILURES+=("FAIL: $1: $2")
}

unquote() {
  local s="$1"
  s="${s%\"}"
  s="${s#\"}"
  printf '%s' "$s"
}
```
DefectDojo `render()` MUST add `--namespace defectdojo` (Pitfall 4: Helm 4 otherwise reads the operator's
kube context namespace — measured `namespace: argocd`) and the issuer `--set` (RESEARCH line 325):
`helm template t kubernetes/defectdojo --namespace defectdojo --set 'defectdojo.django.ingress.annotations.cert-manager\.io/cluster-issuer=gate-issuer' "$@"`.
Consider `--set defectdojo.initializer.staticName=true` if any check compares Job names (RESEARCH anti-pattern).

**Check templates to clone per ID** (RESEARCH §Code Examples table lines 327-347 is the ID list):

| Nexus check (lines) | Shape | Use for DefectDojo IDs |
|---|---|---|
| CHART-LINT (110-116) | `helm lint` with the same `--set` as render | CHART-LINT (issuer set) |
| STORAGECLASS-OMITTED (118-126) | `render \| yq 'select(.kind=="StatefulSet") \| ... \| has("storageClassName")'` → `false` | STORAGECLASS-OMITTED (select the Postgres StatefulSet by name — there are two StatefulSets), INGRESSCLASS-UNSET, VALKEY-EPHEMERAL, POSTGRES-PERSISTENT, INGRESS-ON, TLS-ON, RENDERED-IMAGES, UWSGI-FOOTPRINT, NO-SECRETS-RENDERED |
| STORAGECLASS-OVERRIDE (128-134) | render with `--set x=test`, assert verbatim | STORAGECLASS-OMITTED override half, INGRESSCLASS-UNSET override half |
| PERSISTENCE-ENABLED (136-143) | `yq '.path' "$VALUES"` source-level read | IMAGE-PIN (values tags), SITEURL-MATCHES-HOST |

| JOB-HOOK count (289-292) | `yq ... \| grep -c '^Ingress$'` | INGRESS-ON "exactly 1 Ingress", NO-SECRETS-RENDERED "0 Secret" |
| NO-DEFAULT-PASSWORD (308-319) | the one check NOT through render(); bare render must FAIL and stderr must name the value | ISSUER-REQUIRED (bare render must fail, stderr contains `cert-manager.io/cluster-issuer`), ISSUER-EITHER-KEY (only `cert-manager\.io/issuer` set must succeed), ISSUER-NOT-BOTH (both keys set must fail) |
```bash
if bare_err=$(helm template t "$CHART_DIR" 2>&1 >/dev/null); then
  fail "NO-DEFAULT-PASSWORD" "a bare 'helm template ${CHART_DIR}' SUCCEEDED — the admin credential has a default"
else
  case "$bare_err" in
    *nexus3.rootPassword.secret*) ;;
```

**ISSUER-REQUIRED, ISSUER-EITHER-KEY and ISSUER-NOT-BOTH must bypass `render()`** and call
`helm template t "$CHART_DIR" --namespace defectdojo [--set ...]` directly, because `render()` already sets
`cert-manager.io/cluster-issuer=gate-issuer`: going through it would make the bare case un-bare, the
issuer-only case a both-keys case, and the both-keys case pass for the wrong reason. This is the same trap the
NO-DEFAULT-PASSWORD comment (line 309) names. CHART-LINT likewise needs the issuer `--set` explicitly.

New checks with no Nexus analog: IMAGE-PIN (read `appVersion` from `tar -xOzf charts/defectdojo-1.9.53.tgz defectdojo/Chart.yaml`
and wrapper `Chart.yaml` via `yq`), NO-HELPER-COLLISION (`grep -r 'define "defectdojo\.' "${CHART_DIR}/templates"` → 0 hits),
PLACEHOLDER-ONLY (`grep -iE 'ottawacloudconsulting|letsencrypt|occ-' "$VALUES"` → 0 hits). Each is a plain
grep/yq with the same `if ! x=$(...); then fail ...; elif ...; then fail ...; fi` shape.

## Shared Patterns

### Guard message ↔ gate grep coupling
**Source:** `kubernetes/nexus/templates/job-provision.yaml` lines 38-42 + `scripts/check-nexus-chart.sh` lines 312-319.
**Apply to:** `validate-tls.yaml` and ISSUER-REQUIRED / ISSUER-NOT-BOTH. The template comment names the gate
check; the gate asserts both failure AND the message substring. A reworded message must turn the gate red.

### `CHECK_COUNT` literal in three places
**Source:** `check-nexus-chart.sh` lines 17-19, 82, 392. Header sentence, the `asserting N offline invariants`
echo, and `CHECK_COUNT=N` move together in one commit. Anti-vacuity: the final plan asserts the literal
terminal line `PASS - N checks, 0 failures`.

### Vacuous-pass SKIP guards + 0/1/2 exit contract
**Source:** `check-nexus-chart.sh` lines 21-43, 51-80; `nexus-live-smoke.sh` lines 36-47, 228-236.
**Apply to:** both new scripts. Gate must exit 0 at every intermediate commit; a SKIP prints `SKIP:`; smoke
reports NOTHING RAN rather than ALL PASS when zero checks executed.

### Accumulate every failure, never `|| true` an assertion
**Source:** `check-nexus-chart.sh` lines 94-98; `nexus-live-smoke.sh` lines 111-125. The only permitted
`|| true` is teardown hygiene in the trap (line 74-76 comment says so).

### Pin the kube context on every call; restore the operator's context
**Source:** `nexus-live-smoke.sh` lines 66-71, 979-983, 1045-1047. Every `kubectl` gets `--context "$KIND_CONTEXT"`,
every `helm` gets `--kube-context "$KIND_CONTEXT"`. **The operator's current context is the homelab
(`admin@occ-new`, RESEARCH line 65)** — an unpinned call hits it.

### Credentials never on argv, stdout or in git
**Source:** `nexus-live-smoke.sh` lines 246-251 (urandom generation, gitleaks note), 1024-1035 (stdin heredoc).
Admin password for the login POST comes from the smoke's own generated variable, never scraped from logs.

### Script safety
All scripts committed mode `100644`, invoked `bash scripts/<name>.sh`; the header states it
(`check-nexus-chart.sh` lines 30-31). Verify mode with `git ls-files -s`.

### Append-only ADRs
ADR-023 is a new file; ADR-006 (`2.x.y` example), ADR-009 and ADR-022 are cited, never edited.

- `bash scripts/defectdojo-homelab-validate.sh --url https://<primary-host> --alt-url https://<alternative-host> --context <kube-context> --sync-pass first [--write-state <file>] [--token-file <file>]`

- `--app` (the Argo CD Application name) is also required. Plans pass `--app defectdojo`.
- Exit codes: 0 means ALL PASS or NOTHING RAN, 1 means one or more FAIL, and 2 means a usage or preflight error.
- The `--write-state` JSON holds these keys: `initializer_uid`, `serviceaccount_uid`, `product_count`, `finding_count`, `captured_at`, `app_revision`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-03 | Information Disclosure | admin password / admin token in the gate | mitigate | Password read into a 0600 file under `$OUT` and posted as `password@FILE`. The token is only sent as a `-H @hdr` 0600 file. No `set -x`, no echo of values, and the trap removes `$OUT`. Acceptance greps enforce no `set -x` |
| T-29-05 | Spoofing | CSRF trusted origins (D-05) | mitigate | Positive login with an exact `Origin: https://<host>` on both hosts, plus the negative control `Origin: https://evil.example`, which must return 403 `Origin checking failed` |
| T-29-08 | Tampering | TLS verification in the gate | mitigate | No `--cacert`, `-k` or `--insecure`, and `--proto =https`. The system trust store must verify the LE prod cert (ADR-025). Enforced by acceptance grep |
| T-29-09 | Information Disclosure | homelab literals in a public repo script | mitigate | Hosts, context and namespace are required flags. An acceptance grep forbids `10.40.`, the apex domain and the context name in non-comment lines |
| T-29-SC | Tampering | package installs | accept | This plan installs no npm/pip/cargo packages. It reads an upstream source file via `gh api` at the pinned tag 3.3.200 |

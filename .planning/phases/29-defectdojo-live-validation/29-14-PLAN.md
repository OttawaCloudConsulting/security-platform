Enforce the phase's ordering constraints with an automated gate. The operator then creates the `ci-importer` identity and sets the security-platform secret and variables in a safe order. Claude reads back every value.

Purpose: D-10 makes security-platform the live importer. Setting it before configure.sh defeats dedup (D-13). Setting `DEFECTDOJO_RUNS_ON` before the fork policy is raised exposes the runner to fork PRs.
Output: gate evidence, and settings read-back evidence with no secret values.
</objective>

    1. Build a 0600 header file: `umask 077; H=$(mktemp); printf 'Authorization: Token %s\n' "$(cat ~/.config/defectdojo/homelab-admin.token)" > "$H"`.
    2. Generate a password into a 0600 file (for example `python3 -c 'import secrets;print(secrets.token_urlsafe(20)+"aA1!")' > ~/.config/defectdojo/ci-importer.pw`). Create the user with `POST $DD/api/v2/users/`, using a JSON body built by `jq -n --rawfile pw ~/.config/defectdojo/ci-importer.pw '{username:"ci-importer", password:($pw|rtrimstr("\n")), is_active:true, is_staff:true, is_superuser:false}'` and sent with `-H @"$H" -H 'Content-Type: application/json' --data-binary @<bodyfile>`. Expect 201.
    3. Mint the token with `POST $DD/api/v2/api-token-auth/` and the body `{username:"ci-importer", password:<from file>}`. Write only the `.token` field to `~/.config/defectdojo/ci-importer.token` (0600).
    4. Run `gh secret set DEFECTDOJO_API_TOKEN -R OttawaCloudConsulting/security-platform < ~/.config/defectdojo/ci-importer.token`.
    5. Run `gh variable set DEFECTDOJO_RUNS_ON --body occ-homelab-defectdojo -R OttawaCloudConsulting/security-platform`.
    6. LAST, run `gh variable set DEFECTDOJO_URL --body https://defectdojo.infra.ottawacloudconsulting.com -R OttawaCloudConsulting/security-platform`. Do not set DEFECTDOJO_CA_CERT or DEFECTDOJO_INSECURE.
    7. Run `rm -f "$H" ~/.config/defectdojo/ci-importer.pw ~/.config/defectdojo/ci-importer.token` and any body files.
    Reply "settings-done". Do not paste any token or password.

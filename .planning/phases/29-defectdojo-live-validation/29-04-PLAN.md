**Interface this plan defines.** Every subcommand requires the environment variables `DEFECTDOJO_URL` (https only) and `DEFECTDOJO_ADMIN_TOKEN_FILE` (a 0600 file holding the bare token, the same contract as `defectdojo-configure.sh`), plus the flags `--product <name>` and `--out <evidence-dir>`. Flags never have defaults.
- `snapshot --engagement <name> --label <label>` writes `<out>/<label>-snapshot.json`. It holds the engagement id, the finding count and every finding with the proof script's FIELDS (id, test, title, file_path, active, verified, duplicate, duplicate_finding, false_p, out_of_scope, risk_accepted, is_mitigated).
- `assert-pr-duplicates --branch <b> --main-snapshot <file> --fixture-path <path>` is D-11 step 2.
- `disposition --main-snapshot <file> --fp <id> --oos <id> --ra <id>` is D-11 step 3. It writes `<out>/dispositions.json`.
- `assert-dispositions --dispositions <file>` is D-11 step 4. It is also re-run inside step 5.
- `assert-closed --branch <b> --main-snapshot <file> --dispositions <file>` is D-11 step 5, amended.
- Exit codes: 0 means ALL PASS, 1 means FAIL, and 2 means a usage or preflight error. NOTHING RAN applies as in the homelab gate.

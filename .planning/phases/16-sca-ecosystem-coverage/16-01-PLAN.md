|----------|-------------|
| fixture files → scanners | Deliberately vulnerable content is untrusted input to pip-audit, tflint, Trivy and Checkov |
| fixture files → human reader | A fixture mistaken for real infrastructure or a real dependency set is a false exposure signal |
| requirements.txt → any installer | Nothing must ever `pip install -r` this file |

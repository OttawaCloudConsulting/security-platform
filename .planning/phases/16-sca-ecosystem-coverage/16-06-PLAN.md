    Context must establish why an existing tool could not do the job, using the measured evidence rather

    module blocks and unrelated resource attributes alike. State plainly that tflint has no prior
    precedent in this project — it appears in neither the blueprint, nor `versions.conf`, nor any earlier
    ADR — so adopting it is a genuine stack addition rather than a configuration change.

    Decision must record: tflint v0.64.0 with its bundled `terraform` ruleset, installed in CI by
    checksum-verified `.zip` download (never `curl | sh`, consistent with the Gitleaks precedent and
    ADR-004's intent), invoked as `tflint --recursive` because a repo-root invocation without it sees zero
    `.tf` files and exits 0 — a silent false pass. Record that it runs as a step inside the existing `sca`
    job rather than as a new job, and why: the five check-run names are load-bearing for branch protection.
    Record that it is CI-only for now, deliberately not added to `versions.conf` or the workstation
    installer, and that the local smoke gate therefore skips its tflint sub-check with a message when the
    binary is absent.

    Consequences must carry the honest limitation under Tradeoff: the default ruleset flags a MISSING
    `version` constraint in `required_providers` (and only when the provider is actually used by a
    resource), a registry module with no `version`, and a git module source with no ref or a default-branch
    ref — but it does NOT flag a floating range such as `version = ">= 3.0"`. So "floating or unpinned
    versions are reported as findings" is satisfied through missing constraints and unpinned module
    sources only. Note that flagging every `~>` would be very noisy, since `~>` is Terraform's own
    recommended practice for root modules, and that a custom rule is explicitly out of scope. Also record
    under Tradeoff that tflint exits 2 on findings rather than 1, which required generalising the local
    smoke gate's verdict helper. Under Improved, name the concrete rule ids observed on the live run and
    the gap they close.

    format, linking `adr015-tflint-terraform-pin-checking.md` with today's date and status Accepted. Change

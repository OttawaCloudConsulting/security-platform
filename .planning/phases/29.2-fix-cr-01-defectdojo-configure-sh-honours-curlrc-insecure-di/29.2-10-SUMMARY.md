# Phase 29.2 Plan 10: Token-file trailing line-ending rule (WR-01) Summary

defectdojo-lifecycle-assert.sh and defectdojo-homelab-validate.sh now use the same token-file rule as defectdojo-configure.sh's Python and ADR-029 decision 6. They read the file byte-for-byte, strip at most one trailing CRLF or LF, and then require an exact `^[0-9a-f]{40}$` match under `local LC_ALL=C`. The harness checks both directions: bad files must be refused and valid files must be accepted.

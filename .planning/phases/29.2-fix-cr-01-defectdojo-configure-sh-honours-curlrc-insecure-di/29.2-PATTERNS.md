**Planner must resolve these points (not decided in CONTEXT):**
1. **Two URLs, one hook.** homelab-validate takes `--url` and `--alt-url` (L167-187). It does not read `DEFECTDOJO_URL`. D-06 says the `DEFECTDOJO_RESOLVE` host:port "must equal those of `DEFECTDOJO_URL`". A single `--resolve` can match only one of the two hosts. D-17 says "D-06 where it has a resolve need". Either homelab-validate gets no resolve hook (it runs against real DNS), or the rule is adapted, for example "must match `--url` or `--alt-url`, applied only to the matching host". This is an operator or planner call.
2. **Offline runnability for P-CURLRC.** Required flags are `--url --alt-url --context --namespace --app --sync-pass` (usage L125-152). kubectl is present on ubuntu-latest and on the operator Mac, so a bogus `--context` makes the password read fail at L493-495, and the password POSTs are then skipped. The only token-bearing call is L804, and it runs only with `--token-file`. The only call guaranteed to run offline is `check_tls` L461, which sends no credential. A P-CURLRC case for homelab-validate therefore proves `-q` on the TLS probe, and on L804 only if `--token-file` is passed with a path that runs `measure_count` (check which sync-pass path calls it). `check_tls` uses `fail`, not `abort`, so the run continues after a TLS failure. Assert on the listener log, not on the exit code alone.
3. **Exit codes differ.** A missing binary exits **1** here (L395-399), not 2. The usage and preflight errors exit 2 via `usage_error` (L157-160).
4. **Token-file gaps (WR-01/WR-02 analogue).** L286 checks only `-r`. L426 does the same `tr -d '\r\n'` join as lifecycle L284. D-17 lists D-04/D-05/D-06/D-08, not D-03. Applying the 40-hex check is planner discretion; record the choice.
5. **Leave L464-465 alone.** `openssl x509 -noout -ext subjectAltName` is WR-06, which is deferred.

## Shared Patterns

### Curl invocation head (all four targets plus harness helpers)
**Source:** RESEARCH Pattern 1 (python) and Pattern 2 (bash). The existing pins `--proto =https --proto-redir =https` are at configure L131, lifecycle L409, security.yml L1512 and L1783.
**Apply to:** every DefectDojo curl. `-q` must be argv[1] (list index 1 after `"curl"`, or bash `args[0]` when invoked as `curl "${args[@]}"`). RESEARCH measured that `-q` in second position is ignored and the token is sent.

### Failure line without stderr (D-08/D-18)
**Source:** homelab `measure_count` L806 (already stderr-free) and configure L146 (the body snippet, which is allowed).
**Apply to:** all targets. Python uses `stderr=subprocess.DEVNULL`. Bash uses `2> /dev/null`. Every `.err` file echo is removed from the DefectDojo calls. Format: `method path: curl exit N, http C, TLS verification result V (must be 0): <errormsg>`.

### Transport success predicate
`rc == 0 AND verify == "0" AND http == expect`. `verify` alone is not enough: it is `0` on a refused connection (RESEARCH case G). In the security.yml bodies the verify part is skipped when `tls_mode == "insecure"` (D-16).

### Exit-code convention
0 success, 1 refusal/API/TLS failure, 2 preflight (configure `Failed`/`Preflight` L116-121; lifecycle `exit 2` in preflight L246-292). Exception: homelab-validate uses 1 for a missing binary (L395-399). Bodies: `return 1` (dd-import) / `raise Failed()` (dd-delete). D-06 wants RESOLVE failures to be exit 2 in the bodies too (RESEARCH Pattern 3: `sys.exit(2)`).

### Token handling
Never on argv, `-H @file`, 0600 exclusive create (python `os.O_EXCL` via `write_private` configure L124-127 and security.yml L1426; bash `set -C` lifecycle L287-290), no xtrace, temp dir removed in `finally` / EXIT trap.

### Proof idiom
`proof_pass` / `proof_fail` / `proof_abort` / `proof_finish` L360-386; `why=""` accumulation; one PROOF line per sub-case; never abort from an offline case.

### Plan shape for a security fix plus proof
**Source:** 27-11 (Tasks 1-3, `tdd="true"`, RED evidence recorded before GREEN, exact `grep -c` assertions, scratch negative self-tests, one local commit on a fresh `fix/...` branch from `origin/main`) → 27-12 (operator checkpoint before push and before merge; PR proof run captured to `evidence/`; one rerun only with operator approval) → 27-14 (ADR plus index row). Skip the 27-13 tag step (D-02: no tag, no `v1` move; record the hand-off for 29.4 in STATE.md).

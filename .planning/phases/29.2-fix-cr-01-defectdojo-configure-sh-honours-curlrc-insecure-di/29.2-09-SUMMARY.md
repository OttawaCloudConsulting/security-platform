# Phase 29.2 Plan 09: ADR-029 and the 29.4 release hand-off Summary

**ADR-029 (Accepted) records the Phase 28 CR-01 fix as an append-only extension of ADR-025. Its decisions are: `-q` as argv[1] for all five DefectDojo API clients; success requires exit 0 AND verify 0 AND the expected HTTP code, except on the D-16 insecure path; `DEFECTDOJO_RESOLVE` is a harness-only hook; no curl stderr is printed; token files must be 40-hex; and the CURLRC gate brings the count to 20 checks. It cites only measured values from 29.2-01..08. STATE.md now hands the release to Phase 29.4 and records `defectdojo-live-smoke.sh` as tech debt.**

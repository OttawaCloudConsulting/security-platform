<interfaces>
defectdojo-configure.sh at fdabac9 (bash wrapping a python3 heredoc):
- imports ~L90-95 include os, sys, subprocess, json, urllib.parse (add `re`, `stat`)
- module level: `env = os.environ`, `url = env.get("DEFECTDOJO_URL", "").rstrip("/")`, `token_file = ...`, `ca_file = ...`
- `class Failed(Exception)` -> exit 1; `class Preflight(Exception)` -> exit 2; mapped in the try/finally that removes hdr_path, body_path, resp_path and tmpdir
- `def api(tls_args, method, path, expect, body=None):` builds `cmd = ["curl", "-sS", "--proto", "=https", "--proto-redir", "=https", "-X", method, "-o", resp_path, "-w", "%{http_code}"] + tls_args`, then `-H @hdr_path`; runs with stderr=PIPE; on `code != expect` prints `FAILED: {method} {path} http={code} body={detail}` where detail falls back to proc.stderr (the D-08 leak)
- main(): https refusal (Failed, exit 1) -> token file (`os.stat`, mode & 0o077, unwrapped `open()`, `.strip()`) -> CA file -> `write_private(hdr_path, "Authorization: Token {}\n".format(token))` -> GET, PATCH, re-GET via api()
- success output lines start `NO CHANGE`, `CHANGED:`, `VERIFIED:`

RESEARCH Pattern 3 regex (IPv4 only; the hook is harness-only):
`^([A-Za-z0-9](?:[A-Za-z0-9.-]{0,251}[A-Za-z0-9])?):([0-9]{1,5}):((?:[0-9]{1,3}\.){3}[0-9]{1,3})$`
then host.lower() == urlsplit(url).hostname and int(port) == (urlsplit(url).port or 443). It rejects `*:...`, `+host:...`, `-host:...`, `host:443:a,b`.
curl -w: `%{http_code} %{ssl_verify_result} %{errormsg}` (errormsg last; it may contain spaces and is empty on success; split with maxsplit 2). `%{errormsg}` exists on all curls in use (>= 7.75), so no exit-code map is needed (D-08 research result).

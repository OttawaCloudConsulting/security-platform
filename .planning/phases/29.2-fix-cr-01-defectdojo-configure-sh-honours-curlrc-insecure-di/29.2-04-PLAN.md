- Preflight (grep `# ── Preflight`): URL checks exit 2 with `ERROR:` lines, then `BASE="${DEFECTDOJO_URL%/}"`, then token file `-f`/`-r`/`-s`/mode checks, `WORK="$(mktemp -d)"`, EXIT trap, `HDR="${WORK}/auth-header"`, `cred="$(tr -d '\r\n' < "$CRED_FILE")"` (joins lines: the WR-02 gap), regex `^[A-Za-z0-9._-]+$`, `set -C` exclusive create of HDR, `unset cred`.
- `api_request METHOD PATH OUTFILE EXPECT [BODYFILE]` (grep `api_request() {`): `local args=(-sS --proto =https --proto-redir =https -H @"$HDR" -X "$method" -o "$out" -w '%{http_code}')`, preceded by `# shellcheck disable=SC2191`; `code="$(curl "${args[@]}" "${BASE}${path}" 2> "$err")" || rc=$?`; sets API_ERROR and returns 1; callers turn it into `abort ID "$API_ERROR"` or `fail`.
- `abort ID DETAIL` fails, marks the rest skipped, prints the summary and exits 1. `snippet FILE...` stays.
- Enrichment loop (grep `Enrich up to 10 offenders`): raw `curl -sS ... -w '%{http_code}' ... 2> /dev/null || echo none` per offender id, recording `{duplicate_finding, http}`.

homelab-validate.sh at fdabac9: `set -euo pipefail`; pass/fail print `==> ID: PASS - ...` / `==> ID: FAIL - ...`; print_summary exits 1 on any FAIL. curl sites (grep `curl -sS`): check_tls (`-w '%{http_code} %{ssl_verify_result}'`, parses with `${tls_out##* }`), get_login_form, login POST (`-w '%{http_code} %{redirect_url}'`), dashboard GET, foreign-Origin POST, measure_count (`-H @"$AUTH_HDR"`). Stderr echoes: every `$(tr '\n' ' ' < "$OUT/...err")`. Token file: arg check `-r` (usage_error), read later with `tr -d '\r\n'` into AUTH_HDR.

Multi-field -w parsing: `%{errormsg}` may contain spaces and is empty on success; `%{redirect_url}` may be empty. Use a non-whitespace separator, e.g. `-w '%{http_code}|%{ssl_verify_result}|%{errormsg}'`, and `IFS='|' read -r code verify emsg <<< "$out"` (the last variable takes the remainder), or put errormsg last and split with parameter expansion. Do not use tab as the separator with `read` (tabs are IFS whitespace and empty fields collapse).

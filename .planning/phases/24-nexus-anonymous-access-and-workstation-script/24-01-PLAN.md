| Boundary | Description |
|----------|-------------|
| Provisioning Job → Nexus REST API | Admin-credentialed mutation of security state; a wrong body is a lockout or an open door |
| Unauthenticated client → Nexus | The boundary this phase deliberately moves; this plan ships it CLOSED by default |
| Consumer values → rendered Job env | Consumer-controlled strings cross into a shell environment and then into JSON bodies |

<objective>
Prove NEXUS-02 for npm, PyPI and Helm against a live Nexus: flip the live smoke to the
anonymous-enabled path, invert `ANONYMOUS-PULL-DENIED` into `ANONYMOUS-PULL-ALLOWED`, and add the
two missing ecosystems. Wire the two consumer-visible readiness knobs that Phase 23 shipped inert,
since this plan is already editing every file that would need touching.

Purpose: plan 24-01 left the live gate deliberately asserting the CLOSED posture so its commit
carried no red gate. This plan is where the claim actually flips, and it flips with a byte-count
assertion on every fetch — a 403 EULA refusal is a well-formed 192-byte HTTP response that sails
straight past a bare `200` check, which is the exact false-pass Phase 23's live smoke was built
to catch.

Output: a live gate that measures anonymous pull for three of the four ecosystems (Docker is
plan 24-05), and readiness knobs that are no longer decorative.
</objective>

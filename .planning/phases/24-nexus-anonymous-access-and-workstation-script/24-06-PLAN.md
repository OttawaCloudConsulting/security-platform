<objective>
Build the NEXUS-04 script: `workstation/nexus-setup.sh`, which points one repository's npm, pip and
Helm clients at a given Nexus instance and emits the one sourceable env file that makes two of
those three actually take effect.

Purpose: "per-repo config" means four different things across the four ecosystems and for one of
them it means nothing at all. npm has a native project scope; pip and Helm have none, so a
repo-local file only takes effect through an environment variable; Docker has no per-repository
mechanism whatsoever. A script that writes four files and prints "done" without saying which of
them route anything is the silent-corruption failure mode this project's rules exist to prevent.
This plan writes the honest version of the four writers; plan 24-07 adds the verification pass
that proves them and the Docker decision from plan 24-04.

Output: a non-executable, shellcheck-clean script that satisfies every source-level and
fixture-level assertion in `scripts/check-nexus-setup.sh` except the one that belongs to plan 24-07.
</objective>

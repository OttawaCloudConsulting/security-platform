## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug, harness] Case-insensitive case directories**
- **Found during:** Task 1, first run
- **Issue:** The 4 `GATE-Blocking-*` rows failed with "stub was invoked; .out was written". On macOS APFS, which is case-insensitive, `$W/gate/Blocking-P` and `$W/gate/blocking-P` are the same directory, so the typo rows read the marker and .out left behind by the blocking rows. This was a harness defect. The committed body is correct.
- **Fix:** Gate case directories are now numbered (`<seq>-<mode>-<outcome>`). The Section 3/4 clone directories were numbered from the start.
- **Files modified:** evidence/29.3-mode-logic-proof.sh
- **Commit:** 0ffea2d

**2. [Rule 2 - Critical, T-29.3-14] Isolated Helm homes for every body run**
- **Issue:** The plan names the isolated HELM_CONFIG_HOME/HELM_CACHE_HOME/HELM_DATA_HOME only for REAL-GATE. However, the deps body is the step that runs `helm repo add`, and with `HOME` passed through, that would write to `~/.config/helm`.
- **Fix:** `run_body` passes per-case Helm homes to the deps, gate and negative bodies. DEPS-ABSENT and DEPS-NONHTTPS also assert that no `repositories.yaml` was created.
- **Commit:** b842f4d

**3. [Rule 3 - Blocking] Evidence log ignored by the global gitignore**
- **Issue:** `~/.gitignore:18 *.log` ignores `29.3-03-proof.log`.
- **Fix:** That single file was staged with `git add -f`, which matches the precedent of the committed phase 25/27/28/29 evidence `.log` files.
- **Commit:** b842f4d

**4. [Rule 3] shellcheck findings in the harness itself**
- **Issue:** SC2100 on the unquoted `chart-gate-defectdojo` assignments, and SC2012 on `ls`.
- **Fix:** The assignments are quoted, and `ls` is replaced with a glob array. None of these findings were in the extracted bodies, which are shellcheck-clean.

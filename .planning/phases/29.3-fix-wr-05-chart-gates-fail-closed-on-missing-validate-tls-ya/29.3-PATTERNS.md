**Source:** `check-defectdojo-chart.sh` L114-116 (`fail()`), L552-564 (summary); Nexus L96-98, L391-403.

**Source:** both gate headers ("Never set the executable bit on this file ... Invoke as: bash scripts/...").
**Apply to:** the gates in CI, the negative cases (`bash "${dir}/scripts/check-${CHART}-chart.sh"`, the copy's script, never the workspace's: RESEARCH Pitfall 3), and the proof harness. Never run `chmod +x`.

**Source:** `defectdojo-import-proof.yml` L42-46, L65-67, L109, L121-136.

### Mode allow-list
**Source:** `security.yml` L99-101.

**Source:** `defectdojo-import-proof.sh` L269-276, L286-313.

**Source:** `29.2-12-post-merge.txt`.
**Apply to:** every push, PR, merge and readback step. Each needs operator approval quoted verbatim, a DOING/EXPECT block, and readbacks from origin, never from the local tree.

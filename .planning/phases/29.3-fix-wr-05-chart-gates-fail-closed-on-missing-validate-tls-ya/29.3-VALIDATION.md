## Sampling Rate

- **After every task commit:** Run the quick run command (both gates' last line, actionlint, shellcheck on changed scripts).
- **After every plan wave:** Run the full offline proof (extraction checks, 16+1 mode/bucket cases, local negative cases, RED-vs-fixed comparison).
- **Before `/gsd:verify-work`:** Live PR run green with negative cases passing, operator-approved merge, origin/main readback.
- **Max feedback latency:** 60 seconds (offline).

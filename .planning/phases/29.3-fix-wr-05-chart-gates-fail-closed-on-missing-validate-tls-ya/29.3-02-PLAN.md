## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author -> workflow run | chart files, scripts and Chart.yaml in a PR are untrusted input to the run |

| repo variable -> step | CHART_GATE_MODE is operator-set but may hold a typo |
| internet -> runner | Helm tarball and subchart repositories are downloaded |

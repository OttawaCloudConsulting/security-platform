<objective>
Retain every scan report as a downloadable artifact with an explicit expiry — one artifact per job, five
distinct names, and a glob-based SCA artifact that survives a missing ecosystem.

Purpose: CICD-03 exists to give a future DefectDojo import (DEFECT-01, out of scope this milestone)
something to consume. RESEARCH measured DefectDojo's parser inventory directly: `dojo/tools/` already
contains `checkov`, `gitleaks`, `npm_audit_7_plus`, `pip_audit`, `sarif`, `semgrep`, `tflint` and `trivy`
parsers — every tool in this stack. So the correct retention format is each tool's NATIVE output,
unchanged; normalising it would destroy import fidelity. SARIF is retained alongside the JSON because
tflint produces no JSON in this workflow at all, and without it SCA-03's results would not be retained.

Output: five `upload-artifact` steps and five intolerant assertions, statically validated. Retention is
90 days — the maximum available without a repo-settings change.
</objective>

<notes>
**TARGET REPOSITORY.** `repos/security-platform/`, on the phase branch. All git operations use
`git -C repos/security-platform`.

**Glob, never name, for npm and pip.** Phase 16 hand-forward #1: those reports are numbered PER INPUT
(`npm-audit-1.json`, `pip-audit-2.json`, …) because npm audit operates on a working directory and a
consumer repo is not guaranteed a single manifest at its root. A literal filename would silently retain
one report and drop the rest.

**`if-no-files-found: warn` on the SCA job is deliberate and is the only correct value there.** In a
consumer repo with no `package-lock.json`, `npm-audit-*.json` matches nothing and `error` would turn the
job red on a clean, correct skip — re-breaking Criterion 4. `trivy-fs.json` is unconditional, so the SCA
artifact is never empty. The other four jobs always produce both of their files, so they take `error` —
a missing report there is a real failure.

**One artifact per job. Do not add a gather job.** Five parallel jobs cannot write one artifact name:
`overwrite` defaults to `false` and the second writer fails. Criterion 3 says one per scan job anyway.

**Do not set `overwrite: true`** to "fix" a collision, and do not set `include-hidden-files: true`. This
repo is public; its artifacts are world-downloadable by anyone who can read the repo.

**Do not remove `--redact` from either Gitleaks invocation.** `gitleaks-results.json` becomes a
world-downloadable artifact in this plan. RESEARCH names this the highest-consequence security
consideration in the phase, and the redaction was verified present in the measured SARIF.
</notes>

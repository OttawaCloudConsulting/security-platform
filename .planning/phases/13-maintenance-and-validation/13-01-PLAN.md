<objective>
Make `setup.sh` sourceable for unit testing and stand up the plain-bash test harness that every
later plan in Phase 13 writes assertions into.

This is the **Nyquist Wave 0 scaffolding plan**. No plan that unit-tests by sourcing `setup.sh`
may execute before this one completes. It executes as wave 1 because it has no dependencies.

Purpose: `repos/security-platform/` has zero tests today. `setup.sh` is `set -euo pipefail` with all
dispatch at file scope, so sourcing it runs `check_prerequisites` and the dispatcher — which makes
unit testing `resolve_latest_in_major`, `update_one_tool`, and `tool_health` impossible. Fixing that
first is what lets every later task have a real `<automated>` verify instead of a manual smoke test.

Output: a `[[ "${BASH_SOURCE[0]}" == "${0}" ]]` guard in `setup.sh`, a `tests/` directory with a
glob-sourcing runner, assert helpers, a baseline smoke case, and two recorded GitHub JSON fixtures.
</objective>

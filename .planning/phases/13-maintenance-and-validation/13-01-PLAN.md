       scope. Helpers:
       - `pass <message>` — prints `  pass  <message>`, increments `TESTS_PASSED`
       - `fail <message>` — prints `  FAIL  <message>`, increments `TESTS_FAILED`
       - `assert_eq <expected> <actual> <message>`
       - `assert_contains <haystack> <needle> <message>`
       - `assert_not_contains <haystack> <needle> <message>`
       - `assert_status <expected_code> <actual_code> <message>`
       - `describe <group name>` — prints a section header line

    5. **The test isolation contract** — document these four rules in the header comment and follow
       them in `test_smoke.sh` so later plans have a working example to copy:
       - **Rule 1 — never call an assert helper inside a subshell.** Counter increments inside
         `( ... )` or `$( ... )` are discarded when it exits. A case that asserts inside a subshell
         prints `FAIL` lines while `TESTS_FAILED` stays 0, and the suite exits 0 — a false green that
         makes every downstream `<automated>` verify meaningless. Subshells **emit**; the parent
         **asserts**.
       - **Rule 2 — subshells communicate by echoing.** Capture with
         `out=$( ( source "$SETUP_SH"; set +e; <stubs>; <call>; echo "rc=$?"; echo "$RESULTS" ) 2>&1 )`
         then run the assert helpers in the parent against `$out`.
       - **Rule 3 — `set +e` immediately after sourcing inside a test subshell.** Sourcing `setup.sh`
         imports its `set -euo pipefail`. Without `set +e`, a function returning 1 — which is the
         *expected* outcome in most of these tests — kills the subshell before it can echo anything,
         and the assertion fails for a reason unrelated to what it was testing.
       - **Rule 4 — test `set -e` safety separately and explicitly.** To prove a function does not
         kill an `errexit` caller, run a self-contained snippet as its own process:
         `/bin/bash -euo pipefail -c 'source "$SETUP_SH"; <stubs>; <call> || true; echo SURVIVED'`
         and assert the output contains `SURVIVED`. Do not try to prove it inside a `set +e` subshell.
    6. Source every case file via a glob: iterate `"$TESTS_DIR"/test_*.sh` and `source` each one.
       Guard the glob against the no-match case (`[[ -e "$f" ]] || continue`). This glob is
       load-bearing: later plans add `test_*.sh` files and MUST NOT need to edit `run-tests.sh`.
    7. Print a final summary line `Results: <N> passed, <M> failed` and
       `if [[ $TESTS_FAILED -gt 0 ]]; then exit 1; fi` / `exit 0`.

<objective>
Run the proof once from main by dispatch, then, with the operator's separate approval, tag an annotated `v1.1.1`
and move the lightweight `v1` to the CR-01 merge commit, publish a release, and verify through the API.

Purpose: Mode A consumers fetch `/v1/` and Mode B consumers call `security.yml@v1`; until `v1` moves, every
consumer still runs the cleartext-capable bodies. A security fix with no interface change is a patch
(ADR-018 semver), so `v1.1.1`. Moving `v1` is a force-push of a public tag and gets its own blocking approval
(27-08 precedent).
Output: tags and a release on the remote, one evidence file here.
</objective>

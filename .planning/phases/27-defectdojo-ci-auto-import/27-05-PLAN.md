SMOKE POST-HOOK CONTRACT (defined here, used by 27-06 and the proof workflow):
  Placement: immediately BEFORE the final `print_summary` call (currently L744), because print_summary exits.
  Guard: [ "${#FAILURES[@]}" -eq 0 ] && [ -n "${DD_SMOKE_POST_HOOK:-}" ]
  Exports before invoking: BASE_URL SMOKE_HOST PF_PORT KIND_CONTEXT ADMIN_USER
    DD_CA_FILE="$OUT/ca.crt" DD_ADMIN_PW_FILE="$OUT/admin-pw" DD_SMOKE_OUT="$OUT"
  Invocation: hook_rc=0; bash "$DD_SMOKE_POST_HOOK" --hook || hook_rc=$?
    then pass "POST-HOOK" "<hook> exited 0" or fail "POST-HOOK" "<hook> exited <rc>"
  The EXIT trap still owns the port-forward and cluster teardown. With the variable unset: no new line of
  output and no behaviour change.

PROOF SCRIPT MODES (scripts/defectdojo-import-proof.sh; invoke only as `bash scripts/defectdojo-import-proof.sh`):
  <reports-dir>     entry: preflight -> --extract-only checks -> export DD_PROOF_REPORTS=<abs dir>,
                    DD_SMOKE_POST_HOOK=<abs path of this script> -> run `bash scripts/defectdojo-live-smoke.sh`
                    -> exit with its exit code
  --extract-only    static, no cluster: extract all six side-channel run bodies (dd-download has no run:) with yq, fail on "${{",
                    `bash -n` each body, assert every step env key listed above is present in the committed
                    step (contract drift detection), assert dd-gate bodies identical; exit 0/1
  --hook            live: requires the exported smoke env + DD_PROOF_REPORTS; runs the assertions; prints
                    "PROOF: <ID> PASS|FAIL <detail>" lines and a final "PROOF PASS - <n> assertions" or
                    "PROOF FAIL - <k> of <n>"; exit 0/1/2
Host resolution: write "$DD_SMOKE_OUT/curlhome/.curlrc" containing exactly one line
  resolve = "<SMOKE_HOST>:<PF_PORT>:127.0.0.1"
  and export CURL_HOME to that directory for every body execution and every harness curl.
  (Verified on curl 8.7.1: the curlrc resolve entry is honoured via CURL_HOME.)
  The harness's own curl calls also pass --cacert "$DD_CA_FILE"; none passes -k or --insecure.
DD_URL for bodies = "$BASE_URL" (https://defectdojo.smoke.test:18443). DD_CA_CERT = contents of $DD_CA_FILE.
DD_INSECURE is "" for every network-bound body run.
Body execution (check-detector-parity.sh run_body idiom): write the body to a 0600 temp file; run
  `bash -e <file>` with cwd = a per-run temp dir, env = inherited + GITHUB_OUTPUT (a temp file) + the
  contract names; capture stdout/stderr to $DD_SMOKE_OUT/proof-<label>.log; never echo the token.

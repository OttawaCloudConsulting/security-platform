## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer repository tree → the canonical workflow | An unknown-shape repository is the untrusted input; every path assumption is a defect |
| `gate_mode` input / repo variable → step tolerance | A blank or misspelled value must block, never tolerate |
| discovered Dockerfile path → `docker build -f` | A path read from `git ls-files` is interpolated into a shell command |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-20-01 | Tampering | inlined npm/python/terraform detect steps | mitigate | Measured pathspecs carried across verbatim with their rationale comments; `check-detector-parity.sh` asserts behaviour and parity, not appearance |
| T-20-02 | Tampering | `Detect Dockerfile` step | mitigate | Pathspec set measured in plan 02 against root / nested / dotted / `.dockerfile` / decoy fixtures; byte-exact `SKIP:` string so a false skip is greppable in the log |

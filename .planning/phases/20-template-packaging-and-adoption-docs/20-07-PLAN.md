| Boundary | Description |
|----------|-------------|
| published tag → consumer repositories | After publication, 6+ repositories may execute whatever this ref points at |
| moving `v1` → pinned expectation | A consumer reading `@v1` as immutable is wrong; the docs and the ref shape must not encourage that |
| raw CDN → consumer's copied file | A cached or substituted raw response is what a Mode A consumer actually installs |

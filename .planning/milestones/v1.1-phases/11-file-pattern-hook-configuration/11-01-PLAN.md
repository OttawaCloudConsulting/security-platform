# Plan: 11-01 — Add explicit type/file filters and validate cross-repo

**Phase:** 11 — File-Pattern Hook Configuration
**Requirement:** DIST-04
**Estimated:** ~5 min

## Objective

Make every hook's file-type filtering explicit in the `.pre-commit-config.yaml` so the config is self-documenting, and validate it works cleanly across three repo types (Python+TS, Terraform-only, config-only).

## Current State

All upstream hooks already define `types:` or `files:` in their `.pre-commit-hooks.yaml` manifests, so they already skip when no matching files exist. The local hooks (eslint, npm-audit) already have `files:` patterns. **The config works today** — but the filtering is invisible (hidden in upstream manifests), and the local hooks don't gracefully handle missing toolchains.

## Tasks

### Task 1: Update `generate_precommit_config()` in setup.sh

Add explicit `types:` overrides to upstream hooks in the generated config for documentation clarity and defense-in-depth. Even though upstream already filters, having it in our config makes the behavior visible and protects against upstream changes.

Changes to the heredoc in `generate_precommit_config()`:

1. **terraform_fmt/terraform_validate** — add `types: [terraform]` (upstream already filters by files pattern, but `types:` is cleaner and self-documenting)
2. **ruff/ruff-format** — add `types_or: [python, pyi]` (upstream includes jupyter; we exclude it since we don't use notebooks)
3. **shellcheck** — add `types: [shell]` (matches upstream exactly; explicit is better)
4. **hadolint** — add `types: [dockerfile]` (matches upstream exactly)
5. **yamllint** — already has custom args; add `types: [yaml]` (simplifies upstream's `[file, yaml]`)
6. **markdownlint** — add `types: [markdown]` (matches upstream exactly)
7. **eslint (local)** — already has `files:` filter; add `types_or: [javascript, jsx, ts, tsx]` as belt-and-suspenders
8. **npm-audit (local)** — already has `files:` filter; no type available for package-lock.json, keep as-is
9. **gitleaks** — no change needed (`pass_filenames: false`, scans git diff)

### Task 2: Update the canonical `.pre-commit-config.yaml` in security-platform

Regenerate or manually update `repos/security-platform/.pre-commit-config.yaml` to match the new template.

### Task 3: Validate across all three repos

Run `pre-commit run --all-files` in each repo and verify:
1. **security-platform** (config-only: .md, .yml, .sh) — terraform, ruff, hadolint, eslint, npm-audit all show "(no files to check)Skipped"
2. **terraform-pipelines** (Terraform: .tf, .md, .sh, .yml) — ruff, hadolint, eslint, npm-audit all show "Skipped"
3. **aws-zabbix-monitoring-solution** (Python+TS: .ts, .py, .md, .sh) — terraform_fmt, terraform_validate show "Skipped"
4. All repos exit 0 with no errors

### Task 4: Update ROADMAP.md

Mark Phase 11 complete with validation results.

# Phase 11: File-Pattern Hook Configuration - Context

**Gathered:** 2026-03-22
**Status:** Ready for planning

<domain>
## Phase Boundary

Update the universal `.pre-commit-config.yaml` so every hook has explicit `types:` or `files:` filters. When deployed to repos with no matching files for a given hook, that hook must cleanly skip (exit 0, no errors). The local hooks (eslint, npm-audit) already have `files:` filters. The upstream hooks need to be audited and supplemented where their defaults are insufficient.

</domain>

<decisions>
## Current State Analysis

### Upstream hooks with EXISTING type/file filters (no changes needed):
1. **terraform_fmt** — upstream `files: \.(tf|tofu|tfvars|...)$` — already skips when no .tf files
2. **terraform_validate** — upstream `files: \.(tf|tofu|tfvars|...)$` — already skips
3. **ruff** — upstream `types_or: [python, pyi, jupyter]` — already skips when no .py files
4. **ruff-format** — upstream `types_or: [python, pyi, jupyter]` — already skips
5. **shellcheck** — upstream `types: [shell]` — already skips when no shell scripts
6. **hadolint** — upstream `types: ["dockerfile"]` — already skips when no Dockerfiles
7. **yamllint** — upstream `types: [file, yaml]` — already skips when no .yaml/.yml files
8. **markdownlint** — upstream `types: [markdown]` — already skips when no .md files
9. **gitleaks** — `pass_filenames: false`, scans git diff — runs on all repos (intentional)

### Local hooks with EXISTING file filters (no changes needed):
10. **eslint** — `files: \.(js|jsx|ts|tsx)$` — already skips
11. **npm-audit** — `files: package-lock\.json$` — already skips

### Problem hooks:
- **eslint (local):** Has correct `files:` filter BUT `language: system` means it calls `npx eslint` which will fail if eslint/node is not installed in the target repo. A Terraform-only repo will skip (no matching files), but if a stray .js file exists, it would try to run npx eslint and fail.
- **npm-audit (local):** Has correct `files:` filter BUT `language: system` means it calls `npm audit` which fails if npm is not installed. Similar edge case as eslint.

### Verification needed:
All upstream hooks already have correct type/file filtering. The config is already functional for the success criteria. What needs to happen:
1. Add explicit `types:` overrides in the config for documentation clarity (making the filtering visible in our config, not hidden in upstream manifests)
2. Handle the eslint/npm-audit edge cases for repos without Node.js
3. Run validation across all three repo types (Python+TS, Terraform, config-only)

</decisions>

## Canonical References

### Pre-commit documentation
- `types:` and `types_or:` — pre-commit's built-in file type classification based on file extension and shebang
- `files:` — regex pattern matching on filenames
- When both `types:` and `files:` are set, both must match for the hook to run
- Hooks show "(no files to check)Skipped" when no staged files match — exit 0, no error

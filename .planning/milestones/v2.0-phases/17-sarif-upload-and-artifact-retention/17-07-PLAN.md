status, and do not write a verdict for Criterion 1 or 2 before the user has answered. `auto_advance` does
not apply to an irreversible action on a shared branch.

action. "Looks good" on the evidence is not the same as "merge it" — ask for the merge approval
separately and record the user's literal words, exactly as 16-07 did.

satisfied and Criterion 4 as met by a negative test rather than a live skip, both with explicit user
acceptance. If annotations do not render, record Criterion 2 as NOT OBSERVED, name the probable cause

(VAL-01), which owns the end-to-end proof. Do not add `push: branches: [main]`, do not re-run hoping for a
different result, and do not score it off the Security tab — that is Criterion 1's evidence and they are
different questions.

complete check-run name list on the head SHA, byte-for-byte, with a statement of how many checks code

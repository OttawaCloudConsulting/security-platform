<objective>
Add the six `upload-sarif` steps that make Success Criteria 1 and 2 possible, each with a unique category
and each paired with an intolerant step that asserts the tolerated upload actually landed.

Purpose: category is not a nicety here. GitHub keys analyses on tool name + category, uploading two files
for the same tool and category in one run **fails**, and `trivy-fs.sarif` and `trivy-image.sarif` both
carry `tool.driver.name = "Trivy"` (measured). Per-tool attribution IS Criterion 1. Separately, ADR-001
requires `continue-on-error: true` on upload steps while the project's anti-slop rule forbids silent
fallbacks; the two are reconciled — not traded off — by the tolerated-action / intolerant-assertion pair
that Phase 16 Plan 04 already established in this workflow.

Output: twelve new steps across five jobs, statically validated. No push and no live run — that is 17-05.

<notes>
**TARGET REPOSITORY.** `repos/security-platform/`, on the phase branch. All git operations use
`git -C repos/security-platform`.

**Do not add a job.** Twelve steps go into the five existing jobs. A gather/upload job would break CICD-01
("5 parallel jobs", already Complete) and Phase 18's required-check list.

**Do not rename any job.** The five `name:` values are frozen (em dash U+2014 in each).

**Do not point one upload step at a directory.** `sarif_file:` accepts a directory, and using it would
collapse six analyses into one category, collide the two `Trivy` runs, and destroy the per-tool
attribution that IS Criterion 1.

**Do not disable `wait-for-processing`.** It defaults to `true` and it is what turns an async ingestion
rejection into something the step — and therefore the outcome assertion — can report.

**Do not put `continue-on-error` on a verify step, and do not remove it from an upload step.** ADR-001
governs the upload; anti-slop governs the assertion.

**tflint's guard must be on BOTH its upload and its verify.** An unguarded upload of a missing
`tflint.sarif` fails-then-tolerates; an unguarded verify then fails the job on a clean ecosystem skip,
re-breaking the Criterion 4 skip behaviour Phase 16 spent an entire plan proving.
</notes>

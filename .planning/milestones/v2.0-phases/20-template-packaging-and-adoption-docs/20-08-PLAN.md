Write the first half of the adoption guide: who it is for, how to tell in advance whether the pipeline will work
in a given repository, how to pick a mode, and exactly what each mode costs in files.

Purpose: D-03 puts the adoption docs in a new standalone file rather than growing the 2,400-line blueprint, and
SC3 asks the guide to walk both modes end to end. The structural choice this plan makes is to branch on
REPOSITORY VISIBILITY before branching on mode: the measured blocker in this account is orthogonal to mode —
public repositories ingest SARIF, private ones return 403 — and 37 of the account's 60 repositories are private.

never mentioned. Every command ships with its expected output, following this project's own
`INSTALLATION_GUIDE.md` convention, because a wrong pathspec, a dropped ruleset rule, a mistyped em dash and a
missing caller permission all produce green runs.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| documented command → operator action in another repository | A wrong command in a rollout doc is executed verbatim across 6+ repositories |
| documented `uses:`/raw ref → what a consumer actually installs | A `@main` ref or an unpinned raw URL installs whatever is current, not what was reviewed |
| green check → reader's conclusion | The most likely misreading in this domain, and it has already cost this project a criterion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-06 | Tampering | refs documented for consumers | mitigate | Every raw URL pinned at `/v1/` and asserted to be exactly three; zero `main`/`master` raw refs; `@v1.0.0` named as the immutable option with its cost stated |
| T-20-19 | Elevation of privilege | Mode B caller permissions | mitigate | All three grants shown at job level with the ceiling rule and the silently-green 403 consequence carried across from the canonical caller's own comments |
| T-20-04 | Elevation of privilege | `gate_mode` passthrough | mitigate | The forbidden form appears only inside a prohibition, with the `""`-counts-as-provided mechanism stated |
| T-20-16 | Repudiation | "green means clean" | mitigate | Section 6 pairs five green checks with 19-06's measured finding counts and points at the Security tab and artifacts |
| T-20-17 | Tampering | Mode A fetch from a cached moving tag | mitigate | The measured ~5-minute cache window is documented with the offline `actionlint`/`yamllint` check as the remedy |
| T-20-SC | Tampering | package-manager installs | accept | The guide instructs no package install; the only fetches are three files from a pinned tag over HTTPS |
</threat_model>
